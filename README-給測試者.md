# Pixel Crew（米線部門版）— 給測試者的快速上手

一個跑在你自己電腦上的「多智能體辦公室」：把多個 **Claude Code** / **Codex** CLI 工作階段變成辦公室裡的 NPC，你可以派工、即時看牠們的輸出／思考／工具呼叫，並核准或拒絕權限請求。

這個版本額外多了 **兩種視覺主題可即時切換**：

- 🎮 **像素風**：經典像素辦公室。
- 🏢 **現代 3D**：模擬人生風的 3D 娃娃屋（右下角/左下角有主題切換鈕，兩個世界共用同一份資料與功能，只換外觀）。

> ⚠️ 這是**非官方、獨立**工具，跟 Anthropic / OpenAI 無關。它只是把你自己安裝、自己登入的官方 CLI 包裝起來視覺化，**不會叫你貼 API Key**，驗證與用量都留在底層 CLI。

---

## 1. 系統需求

- **Node.js 22.13 以上**（`node -v` 確認；沒有的話到 https://nodejs.org 裝 LTS）。
- 至少安裝並登入一個 **Claude Code** 或 **Codex** CLI（在終端機能直接跑起來就行）。
- 作業系統：Windows 10 22H2 / 11 或 macOS 皆可。

---

## 2. 安裝與啟動

在解壓後的資料夾裡開終端機：

```bash
# 1) 複製環境設定範本（裡面 TARGET_REPO_PATH 是選填，可先不管）
cp server/.env.example server/.env      # Windows PowerShell: copy server\.env.example server\.env

# 2) 安裝相依套件（第一次會比較久）
npm install

# 3a) 開發模式（前端會熱更新）
npm run dev
#     → 瀏覽器打開 http://localhost:5173

# 3b) 或正式模式（前後端 + WebSocket 全部由一個服務吃）
npm run build
npm run start
#     → 瀏覽器打開 http://127.0.0.1:8787
```

第一次進去會有簡短導覽。左側可以新增 NPC、綁定一個本機資料夾當牠的工作目錄，然後就能派工。

---

## 3. 玩法重點

- **派工**：在下方 Boss 對話框輸入任務送出，NPC 會開始跑，右側/日誌即時串流牠的思考與工具呼叫。
- **核准權限**：NPC 要動敏感操作時會跳出核准請求，可「允許一次 / 拒絕 / 給予範圍規則」。
- **切換主題**：畫面角落的「🎮 像素風 / 🏢 現代 3D」按鈕即時切換；旁邊的縮放條（`－ ▬○▬ ＋ 2x ↺`）是調鏡頭遠近與重置視角。
- **快速圓桌／作戰室**：快速圓桌由目前 NPC 在單一回合模擬 2–4 個觀點並給出結論；作戰室才會召集 2–4 位與目前 NPC 相同 LLM 的臨時同儕辯論（Claude 維持 Claude、Codex 維持 Codex）。點會議桌會直接選取作戰室，需數分鐘並使用該 LLM 用量。
- **預覽 3D 行為**：網址加 `?demo=9` 可放 9 個示範角色到各站點走動（純預覽，不影響真連線）。

---

## 4. 常見問題

- **打不開 / 白畫面**：確認 `node -v` ≥ 22.13，且 `npm install` 沒有報錯。
- **NPC 跑不動**：確認你的 Claude Code / Codex CLI 在終端機能單獨跑起來且已登入。
- **現代 3D 很吃顯卡**：3D 主題是全解析度即時渲染，閒置會自動降到低幀省電；切回像素風時 3D 會完全停止渲染、不佔顯卡。
- **只綁 127.0.0.1**：服務只在本機，不對外開放，狀態存在本地 SQLite。
