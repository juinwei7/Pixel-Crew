# 本機品質與效能診斷 SDD

## 目標

預設在裝置本機保留去識別化的產品訊號，讓使用者依任務成功率、失敗原因與可用性決策；不得預設上傳。

## 資料邊界

只儲存事件分類、數值與時間：WebSocket 重連、長 UI 工作、FPS、核准等待秒數。診斷彙總不含 prompt、工作區路徑、NPC／帳號識別、模型輸出或工具輸入輸出。

## 成功條件

- 營運面板可顯示 Mission 成功率、失敗原因、WebSocket 重連、FPS 分級、長 UI 工作與核准等待。
- 使用者能於功能選單關閉收集，並能下載本機 JSON 診斷包。
- API 只接受已知分類與有界的非負數值；匯出只包含彙總。
