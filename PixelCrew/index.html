WHY PIXEL CREW

四件事，決定要不要花時間裝它。

部門會自己分工

兩個以上 NPC 共用同一個工作資料夾，你只寫目標與驗收標準，部門主管自己決定找誰諮詢、找誰審查，或啟動一段任務鏈。

沒有 API key，因為根本不需要

Pixel Crew 只是編排你電腦上已經安裝、已經登入的官方 CLI；認證、額度、帳單全部留在原本的工具裡。

危險動作永遠等你點頭

即使開啟完全自動核准，rm -rf 之類的危險指令仍會強制跳出確認；部門也絕不會自動 commit、push 或 release。

換一顆大腦，不丟工作

Codex 額度見底、或這題 Claude 更擅長？先整理工作摘要，再把 NPC 交接給另一個 LLM 的新 session 接手。

HOW IT WORKS

從派任務到收工，只有三步。

派下去

打一句話派給某個 NPC，或直接交給一整個部門；NPC 會走到對應工位開始工作。

該問你的時候才問你

要執行指令、審查結果不明確、或任務卡住時才會停下來，核准列直接浮在角色旁邊。

看完整任務日誌收工

最終回覆以 Markdown 完整渲染，工具活動、耗時、來源全部攤在日誌裡，可搜尋、可複製。
