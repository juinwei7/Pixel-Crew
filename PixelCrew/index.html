把 Claude Code 與 Codex，變成同一間像素辦公室裡看得見的工作夥伴。

Pixel Crew 是一個跑在你電腦上的多 agent 工作台。每一個 CLI session 都是一個 NPC—— 派任務、看它走到工位開工、即時讀它的輸出與思考、在畫布上直接核准它想執行的指令。

SCENE 01 · 派任務

派下去，然後看著它走去上班。

在輸入列打一句話，NPC 就動身走到對應的工位——讀檔案、寫程式、上網查、跑終端機。 名牌上跳著已執行秒數，頭上的氣泡即時串流它正在說什麼。

  • 工位＝工具：角色站在哪，就代表 agent 正在用什麼
  • 完成慶祝：任務成功時鄰桌同事會轉頭歡呼，失敗則飄出小烏雲
  • 這段錄影是真實任務的螢幕錄製，沒有剪接
SCENE 02 · 核准

誰在等你，一眼就看到。

Agent 要執行指令時，NPC 會停下來、頭上冒出「?」原地踱步， 核准按鈕直接浮在角色旁邊。不用切視窗、不用翻日誌——遠遠掃一眼就知道誰卡住了。

  • 三個選擇：拒絕／本次皆允許／允許這一次
  • 三段自動核准：關閉、安全（唯讀白名單放行）、完全（危險指令仍強制確認）
  • 每個 NPC 獨立設定，互不影響
SCENE 03 · 圓弧選單

右鍵一按，整套人事作業。

對任何 NPC 按右鍵，五顆按鈕沿弧線彈開：重新命名、個性／職務、像素造型、切換房間、移除人員。

  • 個性系統：給 NPC 一個持久的角色設定（「你是前端 QA，只提問題不改 code」），透過各 CLI 原生機制注入，重啟不會忘
  • 像素工作坊：換造型、上傳自己的動態 GIF 頭像
  • 跨 LLM 交接：Claude 做到一半，整理好進度摘要交給 Codex 接手（或反過來）
SCENE 04 · 鏡頭

你的辦公室，你的視角。

拖曳空白處平移、滾輪或左下拉桿縮放——整數倍率，像素永遠銳利。 雙擊地板或按 ⟳ 一鍵回到預設構圖。

  • NPC 一多，放大追某一個、拉遠看全局
  • 名牌、氣泡、核准列全部跟著鏡頭走
  • 平板可用：單指拖曳平移＋拉桿縮放
SCENE 05 · 任務日誌

每一步，都攤在陽光下。

左圖是進行中：agent 說明它要查什麼，WebSearch 的輸入輸出逐字串流。 右圖是收工：最終回覆以 Markdown 完整渲染——清單、連結、資料來源，外加工具活動數與總耗時。

  • 兩種視角：摘要模式只看結論，活動模式攤開每一次工具呼叫
  • 可搜尋：跨任務全文搜尋目前 NPC 的日誌；程式碼區塊一鍵複製
  • 桌面通知：切去別的視窗時，任務完成或等核准會發系統通知（預設關閉）
SCENE 06 · 跨 LLM 交接與能量

換一顆大腦，不丟工作。

Codex 額度見底、或這題 Claude 更擅長？替 NPC 辦交接班： 系統先整理目前的工作摘要，再交給另一個 LLM 的新 session 接手。

  • 全域工作能量：頂欄常駐兩家 CLI 的即時用量，點開看本次時段／本週／各層級的重置時間
  • 先看能量再換：交接前顯示目標 LLM 的即時用量，避免換過去馬上斷糧
  • 誠實的告知：明確列出跨 LLM 會遺漏什麼（工具狀態、待核准操作），勾選確認才執行；Claude ⇄ Codex 雙向皆可
SCENE 07 · 像素工作坊

你的隊員，長你想要的樣子。

五位官方隊員造型直接換，或上傳自己的像素 GIF——動畫原樣保留， 自動適配 NPC 在辦公室裡的尺寸，走路、工作、歡呼動作照常。

  • GIF 動態頭像：最大 320×320、120 幀，依原始幀時間循環播放
  • 不怕手滑：切換官方造型不會刪除你的自訂角色，隨時換回來
  • 搭配個性系統，讓「財報分析師」看起來真的像財報分析師
SECURITY MODEL

你的 API key 很安全——因為根本沒有 API key。

Pixel Crew 不是另一個要你貼金鑰的服務。它編排與視覺化的，是你機器上已經安裝、已經登入的官方 CLI。認證、額度、帳單全部留在原本的工具裡，Pixel Crew 一概碰不到。

只綁 localhost

伺服器監聽 127.0.0.1，不對外開放；瀏覽器與伺服器之間走本機 WebSocket。

CLI 原生認證

登入狀態由 claude／codex 自己管理，Pixel Crew 只呼叫、不儲存任何憑證。

資料留在本機

對話歷史、NPC 設定、頭像全部存在本機 SQLite 與資料夾，沒有任何雲端上傳或遙測。

危險指令攔截

即使開啟完全自動核准，rm -rf、磁碟操作等危險指令仍會強制跳出確認；打包產物另有自動稽核防止洩漏本機資訊。

GET STARTED

三種上車方式，挑一個。

前提只有兩個：Node.js 22.13+（原始碼模式才需要），以及 Claude Code／Codex CLI 至少安裝並登入一個。

MACOS

一行安裝

自帶執行環境的獨立 App，不需要 Node.js 與 npm。

curl -fsSL https://github.com/juinwei7/\
Pixel-Crew/releases/latest/download/\
install-pixel-crew-macos.sh | /bin/bash
WINDOWS

免安裝打包版

下載 zip 解壓即用，附 SHA-256 校驗檔與安裝指引。

# Releases 頁下載後
install-pixel-crew.cmd
start-pixel-crew.cmd
SOURCE

原始碼模式

任何平台，開發與客製都走這條。

juinwei7/Pixel-Crew.git
cd Pixel-Crew

FAQ

常見問題

要付費嗎？會多花我的額度嗎？

Pixel Crew 本身完全免費（MIT 開源）。它不經手任何計費——你用的是自己 CLI 訂閱或帳號的額度，用量跟直接在終端機跑 CLI 一樣，介面右上還有用量電量條幫你盯著。

支援哪些 agent？

目前支援 Anthropic 的 claude（Claude Code）與 OpenAI 的 codex CLI，兩者可以在同一間辦公室混用，也支援互相交接工作。裝一個就能用，不必兩個都有。

我的程式碼跟對話會被送到哪裡？

Agent 與模型供應商之間的傳輸由官方 CLI 自己處理，跟你直接用 CLI 完全相同。Pixel Crew 新增的部分（對話歷史、NPC 設定）只存在本機 SQLite，伺服器只綁 localhost，沒有任何遙測或雲端同步。

自動核准安全嗎？

三段可調，而且是每個 NPC 獨立設定。「安全」模式只放行唯讀操作白名單；「完全」模式仍有危險指令黑名單（rm 系列、磁碟操作、權限變更等）強制人工確認。不確定就維持預設的「關閉」，每一條指令都會問你。

可以同時開很多個 agent 嗎？

可以，上限 20 個 NPC，並且可以分屬不同的工作資料夾（房間）。左側人員列表支援搜尋、篩選（執行中／需處理／依 provider），畫布可縮放平移，人多也不會迷路。

跟 Anthropic 或 OpenAI 是什麼關係？

沒有任何關係。Pixel Crew 是獨立的非官方工具，未受 Anthropic 或 OpenAI 授權、背書或贊助；「Claude」「Codex」等商標屬於其各自所有者。它做的事情是編排並視覺化你自己安裝、自己登入的官方 CLI。
