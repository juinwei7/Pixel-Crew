CHANGELOG

每次更新，帶來了什麼。

從更專心地閱讀 AI 產出，到現在讓 NPC 自己組部門協作；這裡記錄 Pixel Crew 每個正式版本的改變。

NEW RELEASE · 2.3.1

遠端連得進來，終端也更穩定。

2.3.1 修正原始碼開發模式的遠端白畫面，讓畫面、API 與 WebSocket 經過同一個已驗證的入口；同時強化黑窗終端生命週期、響應式操作與無障礙體驗。

v2.3.1 2026.09.09 查看完整版本內容 ↗
01 / REMOTE ACCESS開發模式不再只看到白畫面

轉接站會辨識正式版與 Vite 開發畫面，將 UI 送到正確服務，同時把 API 與應用程式 WebSocket 留在核心 server。

02 / SAME ORIGIN手機不再連向自己的 localhost

遠端瀏覽器沿用 tunnel 網址呼叫 API 與 WebSocket，登入 cookie 與安全閘道能完整套用到每一個請求。

03 / GATEWAY SAFETY擋住開發伺服器的檔案系統入口

遠端閘道拒絕 Vite 的 /@fs/ 路徑，避免登入後繞過應用程式路由讀取工作樹檔案。

04 / TERMINAL LIFECYCLE黑窗終端更能承受重整與中斷

強化 daemon-backed 終端的啟動、恢復、關閉與版面同步，降低終端失聯或留下無法操作程序的風險。

05 / RESPONSIVE + A11Y窄螢幕、鍵盤與讀屏操作更一致

補齊工作台、工具視窗與輸入區的響應式行為、焦點語意與鍵盤互動，手機與桌面都更容易操作。

06 / CROSS-PLATFORMPTY 測試更貼近 Windows 實際行為

穩定 ConPTY 尺寸偵測與延遲清理測試，讓 macOS、Linux 與 Windows 的終端生命週期持續受到 CI 驗證。
