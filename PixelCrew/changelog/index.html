CHANGELOG

每次更新，帶來了什麼。

從更專心地閱讀 AI 產出，到現在讓 NPC 自己組部門協作；這裡記錄 Pixel Crew 每個正式版本的改變。

NEW RELEASE · 2.5.0

手機版整個重做，不再是縮小的桌面版。

2.5.0 把手機版型全部重建在同一層共用樣式上：斷點從二十四個收到三個，所有對話框共用一個殼，導覽列只留重點、其餘依「作用範圍」分成兩個選單。三個工作模式的導覽列現在完全一致，切換時不會跳。

v2.5.0 2026.09.23 查看完整版本內容 ↗
01 / ONE LAYER斷點從二十四個收到三個

手機、平板、矮螢幕各一個，數值集中在一份共用樣式裡。點擊目標與間距也只剩一組 token，取代散落各處近百次硬寫的 44px。

02 / TOP BAR兩個選單，照「會動到誰」分

導覽列只留工作模式、交辦、用量與健康燈。其餘分成「這位 NPC」（工作位置、供應商、模型、帳號、自動核准、MCP）與「整個 app」（語言、通知、看板、備份、重啟）。

03 / NO JUMP三個模式同一條導覽列

像素、專業、黑窗的內距、間距、控件尺寸與模式鈕寬度現在是同一組數字，切換時上面那排不會位移。

04 / SWIPE模式鈕收成一顆，左右滑就換

窄螢幕上三顆並排的模式鈕會吃掉六成寬度。改成只顯示目前這一個：左右滑到相鄰模式，點一下展開三個選項——不做循環，免得中途誤停在另一個模式。

05 / MORE ROOM對話與報告各拿回一大塊

任務日誌的面板外框從 100px 收到 54px，專業模式報告上方的三列併成兩列、218px 收到 132px。省下來的高度全部給內容。

06 / NO EMOJI圖示不再交給作業系統決定

122 個當圖示用的 emoji 換成一套自製線性圖示：同一個粗細、跟著介面顏色走，不會在 macOS、Windows、Android 各長一個樣。
