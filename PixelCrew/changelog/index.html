NEW RELEASE · 2.3.0

真正的 CLI 終端，現在能留在 Pixel Crew 裡持續工作。

2.3.0 帶來持久化黑窗工作台：把 Claude Code 與 Codex 放進可自由編排的 Workspace 與終端窗格，保留 session 身分並跨重整同步。全域共享記憶、帳號用量與一致的安全確認，讓像素、專業與黑窗三種模式共用同一套可靠本機工作流程。

v2.3.0 2026.09.04 查看完整版本內容 ↗
01 / BLACK WINDOW一個工作台，多個真正的 CLI

以 Workspace 分頁整理 Claude Code 與 Codex 終端；窗格可拖曳、縮放、分割、最小化與最大化。離開畫面或重新整理後，daemon 仍保留真正的 session 與終端身分。

02 / SYNC多個瀏覽器分頁也不互相覆蓋

版面變更帶有版本檢查，遇到其他分頁先更新時會採用最新狀態；拖曳中的本機幾何也能與遠端修改安全合併，避免讓 CLI 變成無法存取的孤兒程序。

03 / AGENT CONTROLS終端裡也能選帳號、模型與權限

每個 Agent pane 都能指定 Claude／Codex、共用或具名稱帳號、模型與 auto-approve 模式。需要重啟 session 的變更會先清楚確認，再安全替換終端身分。

04 / TERMINAL UX字體與語音輸入都留在工作流裡

可調整並保存每個終端的字體大小；本機 Whisper 語音可先轉成可編輯文字，再輸入目前 CLI，不會自動執行或傳送控制字元。

05 / GLOBAL MEMORY所有 Agent 共用一份本機簡報

在介面維護共享 Markdown 記憶，Claude 與 Codex 會透過各自原生指示機制讀取。內容只留在本機，也會納入可驗證的備份與還原流程。

06 / SAFETY危險動作只確認一次，而且不會失焦

移除 NPC、刪除 Workspace、重啟服務與捨棄未儲存修改，統一使用可鍵盤操作的應用程式內確認視窗；等待回覆期間若狀態已改變，操作會重新檢查並安全取消。
