GET STARTED

三種上車方式，挑一個。

前提只有兩個：Node.js 22.13+（原始碼模式才需要），以及 Claude Code／Codex CLI 至少安裝並登入一個。

MACOS

一行安裝

自帶執行環境的獨立 App，不需要 Node.js 與 npm。

curl -fsSL https://github.com/juinwei7/\
Pixel-Crew/releases/latest/download/\
install-pixel-crew-macos.sh | /bin/bash
WINDOWS

免安裝打包版

下載 zip 解壓即用，附 SHA-256 校驗檔與安裝指引。

# Releases 頁下載後
install-pixel-crew.cmd
start-pixel-crew.cmd
SOURCE

原始碼模式

任何平台，開發與客製都走這條。

git clone https://github.com/\
juinwei7/Pixel-Crew.git
cd Pixel-Crew
npm install
npm run dev   # localhost:5173

FAQ

常見問題

部門跟直接派任務給一個 NPC 有什麼不同？

直接派任務只有一個 NPC 處理到底。部門至少兩位 NPC 共用同一個工作資料夾，其中一位是主管；你只要寫目標與驗收標準交給主管，主管會自己決定找專家諮詢、請人審查，或啟動一段 2 到 5 步的任務鏈，中間卡住時才會停下來問你。

部門會自己 commit、push 我的程式碼嗎？

不會。無論走 Quick Consult、Quick Review 還是完整的 Mission，部門都不會自動 commit、push、merge、tag 或建立 release，也不會碰任何登入認證；一般 CLI 的核准提示仍然照常生效。

要付費嗎？會多花我的額度嗎？

Pixel Crew 本身完全免費（MIT 開源）。它不經手任何計費——你用的是自己 CLI 訂閱或帳號的額度，用量跟直接在終端機跑 CLI 一樣，介面右上還有用量電量條幫你盯著。

支援哪些 agent？

目前支援 Anthropic 的 claude（Claude Code）與 OpenAI 的 codex CLI，兩者可以在同一間辦公室混用，也支援互相交接工作。裝一個就能用，不必兩個都有。

我的程式碼跟對話會被送到哪裡？

Agent 與模型供應商之間的傳輸由官方 CLI 自己處理，跟你直接用 CLI 完全相同。Pixel Crew 新增的部分（對話歷史、NPC 設定）只存在本機 SQLite，伺服器只綁 localhost，沒有任何遙測或雲端同步。

自動核准安全嗎？

三段可調，而且是每個 NPC 獨立設定。「安全」模式只放行唯讀操作白名單；「完全」模式仍有危險指令黑名單（rm 系列、磁碟操作、權限變更等）強制人工確認。不確定就維持預設的「關閉」，每一條指令都會問你。

可以同時開很多個 agent 嗎？

可以，上限 20 個 NPC，並且可以分屬不同的工作資料夾（房間）。左側人員列表支援搜尋、篩選（執行中／需處理／依 provider），畫布可縮放平移，人多也不會迷路。

跟 Anthropic 或 OpenAI 是什麼關係？

沒有任何關係。Pixel Crew 是獨立的非官方工具，未受 Anthropic 或 OpenAI 授權、背書或贊助；「Claude」「Codex」等商標屬於其各自所有者。它做的事情是編排並視覺化你自己安裝、自己登入的官方 CLI。
