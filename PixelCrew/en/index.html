WHY PIXEL CREW

Four things worth knowing before you install it.

Departments route themselves

Two or more NPCs share one workspace; you just write a goal and acceptance criteria, and the lead decides who to consult, who reviews, or when to run a task chain.

No API key, because none is needed

Pixel Crew only orchestrates the official CLIs already installed and signed in on your machine; authentication, usage, and billing all stay in those tools.

Dangerous actions always wait for you

Even with full auto-approval on, commands like rm -rf still force a confirmation; a department never auto-commits, pushes, or releases either.

Switch brains without dropping the work

Running low on Codex, or is Claude better suited? Summarize the work first, then hand the NPC off to a fresh session on the other model.

HOW IT WORKS

From assigned to done, in three steps.

Assign it

Type a task for one NPC, or hand it straight to a whole department; the NPC walks to the matching workstation and gets to work.

It only interrupts you when it matters

It stops only to run a command, when a review is inconclusive, or when something's actually blocked — the approval bar floats right beside the character.

Read the full task log when it's done

The final reply renders as full Markdown; tool activity, duration, and sources are all in the log, searchable and copyable.
