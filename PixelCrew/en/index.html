SECURITY MODEL

Your API key is safe—because there is no API key.

Pixel Crew orchestrates the official CLIs already installed and authenticated on your computer. Authentication, model traffic, usage, and billing stay with those tools.

Loopback only

The local server listens on 127.0.0.1 and is not exposed to the network.

Native authentication

Claude Code and Codex own sign-in; Pixel Crew does not store provider credentials.

Local data

Conversation history, NPC settings, drafts, and avatars stay on your computer.

Command guardrails

Destructive shell and disk operations still require confirmation.

Release audits

Packaging checks reject local paths, secrets, and unsupported runtime structures.

No telemetry

There is no Pixel Crew cloud upload, analytics SDK, or tracking service.

GET STARTED

Choose the setup that fits.

You need at least one installed and signed-in Claude Code or Codex CLI. Node.js 22.13+ is only required when running from source.

MACOS

One-command install

A self-contained app with its own verified runtime.

curl -fsSL https://github.com/juinwei7/Pixel-Crew/releases/latest/download/install-pixel-crew-macos.sh | /bin/bash
WINDOWS

Portable package

Download the x64 ZIP, extract it, and launch it.

install-pixel-crew.cmd
start-pixel-crew.cmd
SOURCE

Development mode

Run and customize Pixel Crew on any supported platform.

git clone https://github.com/juinwei7/Pixel-Crew.git
cd Pixel-Crew
npm install
npm run dev
FAQ

Frequently asked questions

Is Pixel Crew free?

Yes. Pixel Crew is MIT-licensed and free to use. Your provider subscription remains separate.

Which agents are supported?

Anthropic Claude Code and OpenAI Codex CLI. Use either provider alone or both in one office.

Where do my code and conversations go?

Provider traffic is handled by each official CLI. Pixel Crew stores its added state locally and binds only to localhost.

Does Pixel Crew need an API key?

No. It calls official CLIs that you installed and authenticated yourself.

Can I use multiple projects?

Yes. Project folders become rooms, and up to 20 NPC sessions can work across them.

Is Pixel Crew affiliated with Anthropic or OpenAI?

No. Pixel Crew is an independent, unofficial project and is not endorsed or sponsored by either company.
