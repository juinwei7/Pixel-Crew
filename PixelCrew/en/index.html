Real CLI terminals can now stay and keep working inside Pixel Crew.

Version 2.3.0 introduces the persistent Black Window workbench: arrange Claude Code and Codex across workspaces and terminal panes while preserving session identity through navigation and reloads. Shared global memory, per-account usage, and consistent safety confirmations connect Pixel, Professional, and Black Window modes into one reliable local workflow.

01 / BLACK WINDOWOne workbench, multiple real CLIs

Organize Claude Code and Codex terminals in workspace tabs. Panes move, resize, split, minimize, and maximize; leaving the view or reloading no longer discards the daemon-backed session or terminal identity.

02 / SYNCBrowser tabs no longer overwrite each other

Layout writes use version checks and adopt newer state when another tab wins the race. Local drag geometry merges safely with remote changes, preventing CLI processes from becoming orphaned or unreachable.

03 / AGENT CONTROLSChoose account, model, and permissions in the terminal

Each Agent pane can select Claude or Codex, a shared or named account, its model, and auto-approve mode. Changes that require a new session are explained first, then replace terminal identity safely.

Save a readable font size per terminal. Local Whisper voice input becomes editable text in the active CLI and never executes automatically or passes control characters through.

Maintain shared Markdown memory in the app; Claude and Codex receive it through their native instruction mechanisms. It remains local and is included in validated backup and restore flows.

06 / SAFETYDangerous actions ask once and keep context

Removing an NPC, deleting a workspace, restarting services, or discarding edits now uses one keyboard-accessible in-app confirmation. If live state changes while it is open, the operation rechecks and cancels safely.

SIGNATURE · 2.0.0

Hand the work to a department, and let the lead decide.

A department is two or more NPCs sharing one workspace, one of them designated the lead. Create one directly with the Department Creator: fill in a purpose, headcount, and provider, and AI drafts complementary roles and personas — you just pick who leads. From then on, every time you hand off work you only write a goal and acceptance criteria; the lead decides whether to consult an expert, ask for a review, or run a full task chain.

  • AI-planned departments: fill in purpose, headcount, and provider; AI drafts complementary roles and you pick a lead
  • Quick Consult / Quick Review: two-step, read-only collaboration — an expert advises or reviews, the lead executes and finalizes
  • Department Mission: a 2–5 step task chain that always starts with execute, with a different NPC doing each review step; failed reviews get up to two automatic correction rounds
  • Only five things stop for you: plan approval, an inconclusive review, a used-up correction budget, a failed step, or a member going offline — everything else hands off automatically
  • No mode ever auto-commits, pushes, merges, tags, or releases, and none of them touch your authentication

SCENE 01 · ASSIGN WORK

Assign it, then watch it go to work.

Type a task and the NPC walks to the matching workstation — to read files, write code, search the web, or use the terminal. Its nameplate shows elapsed time while a speech bubble streams live output.

  • Workstation = tool: where the character stands shows what the agent is using
  • Completion reactions: nearby teammates celebrate success; failures produce a small storm cloud
  • This is an unedited recording of a real task
SCENE 02 · APPROVALS

See who needs you, at a glance.

When an agent wants to run a command, its NPC stops, paces with a question mark overhead, and the approval controls float right beside the character. No window switching, no digging through logs — one glance across the office tells you who's stuck.

  • Three choices: deny, allow for this task, or allow once
  • Three auto-approval levels: off, safe (a read-only allowlist), or full (dangerous commands still force a confirmation)
  • Each NPC has independent settings
SCENE 03 · RADIAL MENU

One right-click, every setting for this character.

Right-click any NPC to rename it, edit its persona, change its look, switch rooms, or safely remove it — and to ask another NPC at the same workstation for a read-only Consult or Review. For a bigger job, just create a department.

  • Persistent personas: give an NPC a durable role ("You're a frontend QA — only raise issues, never touch code") injected through each CLI's native mechanism; it survives restarts
  • Pixel Workshop: switch looks or upload your own animated GIF avatar
  • Cross-LLM handoff: let Claude summarize its progress partway through and hand off to Codex (or the other way around)
SCENE 04 · CAMERA

Your office, your point of view.

Drag empty space to pan, use the wheel or the lower-left slider to zoom — always in crisp integer steps. Double-click the floor or press ⟳ to reset to the default framing.

  • Zoom in to follow one NPC, or pull out to see the whole office
  • Nameplates, bubbles, and approval controls move with the camera
  • Tablet-friendly: one-finger pan plus a slider for zoom
SCENE 05 · TASK LOG

Every step, out in the open.

The left panel shows a task in progress: the agent explains what it's about to look up while a WebSearch tool's input and output stream in live. The right panel shows the finished result: the final reply rendered as full Markdown — lists, links, sources — plus the tool-call count and total duration.

  • Two views: summary mode for the conclusion, activity mode for every tool call
  • Searchable: full-text search across this NPC's task history; one-click copy for code blocks
  • Desktop notifications: get a system notification when a task finishes or needs approval while you're in another window (off by default)
SCENE 06 · HANDOFFS & ENERGY

Switch brains without dropping the work.

Running low on Codex allowance, or is this one better suited to Claude? Hand an NPC off between LLMs: the system first summarizes the current work, then hands it to a fresh session on the other model.

  • Global work energy: the top bar always shows live usage for both CLIs; open it for session, weekly, and per-model reset times
  • Check energy before switching: see the target LLM's live usage before handing off, so you don't run out right after switching
  • Honest warnings: it lists exactly what won't carry over (tool state, pending approvals) and requires a confirmation checkbox before proceeding; works Claude ⇄ Codex in either direction
SCENE 07 · PIXEL WORKSHOP

Make your crew look the way you want.

Swap between five official crew designs, or upload your own pixel GIF — animation timing is preserved and the avatar is automatically fitted to the NPC's size in the office, walking, working, and celebrating as usual.

  • Animated GIF avatars: up to 320×320 and 120 frames, looping at their original frame timing
  • Safe to switch: choosing an official look never deletes your custom character — switch back anytime
  • Pair it with the persona system so your "financial analyst" actually looks like one
SECURITY MODEL

Your API key is safe — because there is no API key.

Pixel Crew isn't another service asking you to paste in a key. It orchestrates and visualizes the official CLIs already installed and signed in on your machine. Authentication, usage, and billing all stay in those tools — Pixel Crew never touches them.

Localhost only

The server listens on 127.0.0.1 and is never exposed publicly; the browser talks to it over a local WebSocket.

Native CLI authentication

Sign-in is managed by claude/codex themselves — Pixel Crew only invokes them, never stores any credential.

Data stays local

Conversation history, NPC settings, and avatars all live in a local SQLite database and folders — no cloud upload, no telemetry.

Dangerous-command guardrails

Even with full auto-approval on, destructive commands like rm -rf and disk operations still force a confirmation; a department Mission never auto-commits, pushes, merges, tags, or releases either.

FAQ

Frequently asked questions

How is a department different from assigning a task to one NPC?

Assigning a task directly means a single NPC handles it start to finish. A department has at least two NPCs sharing one workspace, one of them the lead — you just write a goal and acceptance criteria and hand it to the lead, who decides whether to consult an expert, ask for a review, or run a 2-to-5-step task chain, stopping to ask you only when something's actually blocked.

Will a department auto-commit or push my code?

No. Whether it's running Quick Consult, Quick Review, or a full Mission, a department never auto-commits, pushes, merges, tags, or releases, and it never touches your authentication; normal CLI approval prompts still apply.

Is it free? Does it use more of my allowance?

Pixel Crew itself is completely free and MIT-licensed. It never handles billing — you're using your own CLI subscription or account allowance, exactly as if you ran the CLI directly; the usage meters in the top bar help you keep an eye on it.

Which agents are supported?

It currently supports Anthropic's claude (Claude Code) and OpenAI's codex CLI. Both can share one office and hand work back and forth. Installing just one is enough to get started.

Where do my code and conversations go?

Traffic between an agent and its model provider is handled entirely by the official CLI, exactly as it would be if you ran that CLI directly. What Pixel Crew adds — conversation history, NPC settings — lives only in local SQLite; the server only binds to localhost, with no telemetry or cloud sync.

Is auto-approval safe?

It has three levels, set independently per NPC. "Safe" only allows a read-only command allowlist. "Full" still forces a manual confirmation for a blocklist of dangerous commands (rm and friends, disk operations, permission changes, etc). If you're unsure, leave it on the default "off" — every command will ask first.

Can I run a lot of agents at once?

Yes — up to 20 NPCs, and they can be split across different working folders (rooms). The personnel list on the left supports search and filters (running / needs attention / by provider), and the canvas pans and zooms, so it stays easy to navigate even with a full office.

Is Pixel Crew affiliated with Anthropic or OpenAI?

No. Pixel Crew is an independent, unofficial tool, not authorized, endorsed, or sponsored by Anthropic or OpenAI; "Claude," "Codex," and related trademarks belong to their respective owners. What it does is orchestrate and visualize the official CLIs you've installed and signed into yourself.
