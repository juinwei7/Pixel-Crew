What changed in each release.

From focused reading for long AI output to NPCs now forming their own departments — this is the history of every Pixel Crew release.

NEW RELEASE · 2.3.0

Real CLI terminals can now stay and keep working inside Pixel Crew.

Version 2.3.0 introduces the persistent Black Window workbench: arrange Claude Code and Codex across workspaces and terminal panes while preserving session identity through navigation and reloads. Shared global memory, per-account usage, and consistent safety confirmations connect Pixel, Professional, and Black Window modes into one reliable local workflow.

v2.3.0 2026.09.04 View full release notes ↗
01 / BLACK WINDOWOne workbench, multiple real CLIs

Organize Claude Code and Codex terminals in workspace tabs. Panes move, resize, split, minimize, and maximize; leaving the view or reloading no longer discards the daemon-backed session or terminal identity.

02 / SYNCBrowser tabs no longer overwrite each other

Layout writes use version checks and adopt newer state when another tab wins the race. Local drag geometry merges safely with remote changes, preventing CLI processes from becoming orphaned or unreachable.

03 / AGENT CONTROLSChoose account, model, and permissions in the terminal

Each Agent pane can select Claude or Codex, a shared or named account, its model, and auto-approve mode. Changes that require a new session are explained first, then replace terminal identity safely.

04 / TERMINAL UXFont sizing and voice stay in the workflow

Save a readable font size per terminal. Local Whisper voice input becomes editable text in the active CLI and never executes automatically or passes control characters through.

05 / GLOBAL MEMORYEvery agent shares one local brief

Maintain shared Markdown memory in the app; Claude and Codex receive it through their native instruction mechanisms. It remains local and is included in validated backup and restore flows.

06 / SAFETYDangerous actions ask once and keep context

Removing an NPC, deleting a workspace, restarting services, or discarding edits now uses one keyboard-accessible in-app confirmation. If live state changes while it is open, the operation rechecks and cancels safely.

v2.1.0 2026.09.01

Account isolation, Focus workbench, and local voice input

Each NPC can now use its own Claude Code or Codex account, alongside /goal, up to four Focus Reader panes, and multi-agent execution boundaries that are previewed and enforced.
